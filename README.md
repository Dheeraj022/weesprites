# Wee Sprites Preschool & Day Care

Official website for **WEE SPRITES** — Pre-school & Day Care.

## 🚀 Overview
A modern, responsive, and animated preschool web application built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**.

### Features
- 🌟 **Dynamic Dual-Slide Hero Carousel:** Highlights student admissions and franchise opportunities with automated transitions and interactive controls.
- 🎨 **Playful Brand Design:** Custom Lilac (`#E8D7FF`), Violet (`#6127B8`), and Sunshine Yellow (`#FFD83D`) color palette.
- 🫧 **Organic Blob Morphing Animations:** CSS & Framer Motion driven fluid animations.
- 🏫 **Comprehensive Sections:**
  - About Wee Sprites
  - Curriculum & Learning Approach
  - Programs (Playgroup, Pre-Nursery, Nursery, LKG, UKG, Daycare & Evening Activities)
  - Interactive Facilities Showcase
  - Gallery & Events
  - Franchise Opportunities with Lead Inquiry Form
  - Contact Us & Location Map
- 📱 **Fully Responsive & Accessible:** Optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack
- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & Lucide React Icons
- **Language:** TypeScript

---

## 💻 Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or configured port) in your browser.

To create a production build:

```bash
npm run build
npm start
```
